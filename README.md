# Sites de démonstration HL Booking Pro

Sites **fictifs** qui intègrent le widget de réservation HL Booking Pro, pour faire des essais comme un vrai client.

- `index.html` : restaurant fictif (widget restaurant dans la page + bouton qui ouvre une fenêtre)
- `hotel.html` : hôtel fictif (widget hôtel)
- `essai.html` : page d'essai libre (`?id=…&mode=auto|restaurant|hotel&display=inline|button`)

L'adresse de l'application et l'identifiant de l'établissement se règlent dans `config.js`.

Les réservations faites sur ces pages sont **réelles** : elles sont enregistrées dans le compte de l'établissement et déclenchent les vrais e-mails de confirmation.
